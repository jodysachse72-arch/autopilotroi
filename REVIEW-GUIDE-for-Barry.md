# Working on AutoPilotROI in ChatGPT — Start here, Barry

For the complete connection checklist and fallback prompt, see `BARRY-CHATGPT-HANDOFF.md`.

You can now work on AutoPilotROI by talking to ChatGPT in the shared project. You do not need to touch code, write technical instructions, or use Vercel comments.

## The whole process

1. Open the shared AutoPilotROI project in ChatGPT.
2. Tell ChatGPT which page you are looking at and what you want changed.
3. Add a screenshot if it makes the issue easier to point out.
4. ChatGPT makes the change, checks it, and gives you a Vercel preview when it is ready to review.
5. Look at the preview and say what you like or what still needs changing. Keep talking in the same conversation until it feels right.

That is the entire workflow.

## Talk normally

You can be direct and informal. These are all complete requests:

- “This headline doesn’t sound like us. Make it more confident but not hypey.”
- “The form is confusing here. Make the next step obvious.”
- “I don’t like how these cards look on my phone.”
- “Change this sentence to: …”
- “Something broke after I clicked Continue. Figure out what happened.”
- “Let’s go through the homepage together. I’ll tell you what bothers me.”

You can give one change or a group of related changes. Exact replacement wording is useful when you have it, but you do not need to know the technical solution.

## What ChatGPT handles

ChatGPT will find the relevant code, account for connected backend behavior, make the changes, run appropriate checks, and prepare the review link. If an important decision is genuinely unclear, it will ask you a focused question.

## Two useful habits

- Include the page name or paste the Vercel preview link when possible.
- Never paste passwords, API keys, or other secrets into the conversation.
